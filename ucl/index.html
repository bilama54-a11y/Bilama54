Comment sont attribués les points de tier ?

Attaque (buts marqués/match) : rangs 1-18 → +1 (OVER), 19-29 → 0, 30-36 → −1 (UNDER).

Défense (buts encaissés/match, #1 = meilleure défense) : rangs 1-18 → −1 (UNDER), 19-29 → 0, 30-36 → +1 (OVER).

Le classement suit les moyennes par match, pas les totaux : une équipe avec un match de moins n'est pas pénalisée. Les zones de qualification de la C1 (1-8, 9-24, 25-36) sont rappelées dans le tableau.

Chaque club ne joue que 8 matchs (4 à domicile, 4 à l'extérieur) : le mode split reste fragile en début de phase de ligue, le mode global est conseillé tant que les échantillons sont petits.

ℹ️ Source des données & synchronisation

Données : League Phase de la Ligue des Champions (36 clubs, 8 journées), reconstruites match par match depuis l'API publique ESPN (splits Domicile/Extérieur exacts) et rafraîchies toutes les 6 h par GitHub Actions.

L'app se resynchronise automatiquement à l'ouverture, au retour au premier plan et dès que l'Android retrouve Internet. Hors-ligne, le dernier instantané est conservé.
