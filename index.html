3. Score projeté : Pts_A = Pace_proj × ((ORtg_A + DRtg_B)/2 /100) ; Pts_B = idem
4. Proba : Win% = (Pts_A^14)/(Pts_A^14+Pts_B^14) (exponent 14 calibré NBA)
5. Value : Edge = Spread_modèle − Spread_book. Si |Edge| ≥2 pts → bet recommandé.
