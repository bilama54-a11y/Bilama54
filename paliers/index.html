Comment sont attribués les paliers ?

Attaque (buts marqués/match) : ≥ 1,40 → palier 1 +1 (OVER) · 1,00 – 1,39 → palier 2 0 · < 1,00 → palier 3 −1 (UNDER).

Défense (buts encaissés/match, logique inverse) : ≤ 1,00 → palier 1 −1 (UNDER) · 1,01 – 1,39 → palier 2 0 · ≥ 1,40 → palier 3 +1 (OVER).

Aucun classement, aucune répartition 50/30/20 : seules comptent les valeurs par match. Une équipe peut donc être seule dans son palier, ou à cheval sur deux journées.

ℹ️ Source des données & synchronisation

Modèle par seuils : attaque ≥ 1,40 but/match → +1 OVER · 1,00–1,39 → 0 · < 1,00 → −1 UNDER. Défense en miroir : ≤ 1,00 encaissé → −1 · 1,01–1,39 → 0 · ≥ 1,40 → +1.

Données : API officielle Fantasy Premier League (splits Domicile/Extérieur exacts), rafraîchie toutes les 6 h par GitHub Actions et publiée sur le site. Fusion temps réel via l'API ESPN quand elle est plus à jour.

L'app se resynchronise automatiquement à l'ouverture, au retour au premier plan et dès que l'Android retrouve Internet. Hors-ligne, le dernier instantané est conservé.
